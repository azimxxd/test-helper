# Test Helper

Расширение для Chrome: разбирает тестовый вопрос на любом сайте и показывает
ответ с объяснением. По желанию само отмечает нужный вариант.

Работает в двух режимах: берёт вопрос из разметки страницы или снимает
скриншот, если вопрос нарисован картинкой либо спрятан в чужом фрейме.

## Что нужно

- Node.js 20+
- Ключ Anthropic API с console.anthropic.com
- Chrome или любой браузер на Chromium (Edge, Arc, Brave, Яндекс)

## Установка

**1. Сервер.** Он держит ключ у себя, расширение ключа не видит.

```bash
cd server && npm install && cp .env.example .env
```

Выбери провайдера и впиши его ключ в `server/.env`, затем запусти:

```bash
cd server && npm start
```

**2. Расширение.** Открой `chrome://extensions`, включи «Режим разработчика»,
нажми «Загрузить распакованное» и выбери папку `extension`.

**3. Проверка.** Открой настройки расширения. Внизу должно гореть
«● сервер на связи».

По умолчанию расширение ничего не меняет на странице: по `Alt+Q` в углу
появляется ответ и через три секунды исчезает. Там, где есть варианты, это
буква. Там, где ответ надо вписывать, это само значение: число, слово или
короткое выражение. Клик по плашке копирует ответ в буфер обмена.
Отмечает вариант только `Alt+A`, и только если ты его нажмёшь.

## Горячие клавиши

| Клавиши | Что делает |
|---|---|
| `Alt+Q` | Разбирает вопрос, показывает ответ в панели |
| `Alt+A` | Решает и сразу отмечает вариант на странице |
| `Alt+S` | Решает по скриншоту видимой части экрана |
| `Alt+X` | Показать или скрыть панель |

Клавиши меняются на странице `chrome://extensions/shortcuts`.

Ничего не срабатывает само: расширение просыпается только по твоей команде.

## Настройки

- **Как показывать ответ.** Три режима, по умолчанию «Только вариант»:

  | Режим | Что видно | Размер |
  |---|---|---|
  | Панель | вопрос, ответ, уверенность, разбор | 380 px, остаётся на экране |
  | Подсказка | ответ и текст варианта | до 340 px, исчезает сама |
  | Только вариант | буква или вписываемый ответ | от 30 px, исчезает сама |

  В режиме «Только вариант» сервер не запрашивает разбор вовсе, поэтому ответ
  приходит примерно вдвое быстрее и тратит в пять раз меньше токенов.
- **Угол экрана.** Подсказку можно поставить в любой из четырёх углов.
- **Подсветка варианта на странице.** По умолчанию выключена: страница
  остаётся нетронутой, ответ виден только в углу. Включается галочкой.
- **Через сколько секунд исчезает подсказка.** По умолчанию 3.
- **`Alt+Q` тоже выбирает вариант.** По умолчанию выключено: `Alt+Q` только
  показывает, отмечает вариант `Alt+A`.
- **Глубина раздумий.** `low` для простых вопросов, `high` и выше для задач по
  математике и физике. Чем выше, тем дольше и дороже.
- **Язык объяснения.** Русский, казахский, английский или как в вопросе.
- **Токен доступа.** Если задать `THELPER_TOKEN` в `server/.env` и то же
  значение в настройках, сервер будет отвечать только твоему расширению.

## Полноэкранный режим

Есть два разных «полных экрана», и ведут они себя не одинаково.

`F11` или зелёная кнопка на Маке разворачивают окно браузера. Страница при
этом рисуется как обычно, расширение работает без оговорок.

Сайт может развернуть свой блок через `requestFullscreen`, так делают
плееры и некоторые просмотрщики тестов. В этом режиме браузер показывает
только сам блок, а всё, что лежит за его пределами, не рисуется вовсе.
Расширение ловит событие `fullscreenchange` и переносит свою панель внутрь
развёрнутого блока, а при выходе возвращает обратно.

## Как он находит вопрос

Три способа подряд, побеждает тот, что ближе к курсору:

1. Настоящие `radio` и `checkbox` вместе с подписями.
2. Блоки с говорящими ролями и классами: `option`, `answer`, `variant`.
3. Одинаковые соседние блоки — сюда попадают варианты с любыми классами.

Курсор решает, какой вопрос разбирать, когда на экране их несколько. Если
рядом вариантов нет, берётся ближайший к курсору блок текста — так работают
вопросы со свободным ответом.

Не нашёл вопрос — выдели его мышкой и нажми `Alt+Q`, выделение всегда в
приоритете. Совсем сложную вёрстку берёт `Alt+S`.

## Тесты

```bash
node test/run.mjs
```

Проверяют разбор ответа модели и склейку потока событий.

## Что внутри

```
server/server.js      прокси к провайдеру, стримит ответ через SSE
server/providers.js   каталог провайдеров и чистка тегов <think>
server/model-config.js параметры раздумий по поколениям моделей
extension/background.js  поиск вопроса, выбор варианта, запросы к серверу
extension/content.js     панель и исчезающая подсказка
extension/tracker.js     запоминает позицию курсора
extension/options.html   настройки
```

## Провайдеры

Задаётся через `THELPER_PROVIDER` в `server/.env`.

| Провайдер | Цена | Скриншоты | Чем хорош |
|---|---|---|---|
| `gemini` | бесплатно | да | лучший бесплатный выбор, ключ на aistudio.google.com |
| `groq` | бесплатно | нет | очень быстрый, сильная математика |
| `cerebras` | бесплатно | нет | крупная модель Qwen3 |
| `openrouter` | бесплатно | нет | DeepSeek R1, но суточный лимит небольшой |
| `anthropic` | платно | да | самый точный |

Сколько тратит один вопрос, замерено на Gemini в режиме «Только вариант»:

| Что решаем | Входных токенов | Выходных |
|---|---|---|
| Вопрос без контекста страницы | около 280 | около 22 |
| Вопрос с контекстом страницы | около 930 | около 22 |
| Скриншот | около 1430 | около 90 |

Упирается всё не в токены, а в число запросов. Свой лимит видно на
странице https://ai.dev/rate-limit, а когда он превышен, провайдер сам
называет его в тексте ошибки.

Лимиты бесплатных тарифов, порядок величин на сентябрь 2026:

| Провайдер | Запросов в минуту | Запросов в сутки |
|---|---|---|
| Gemini | 15 | 1500 |
| Groq | 30 | 14400 |
| Cerebras | 30 | смотри панель |
| OpenRouter | 20 | 200 |

Свои лимиты проверяй в панели провайдера, они меняются. На бесплатных
тарифах запросы обычно используются для обучения моделей, имей это в виду.

### Запасной провайдер

`THELPER_FALLBACK` в `server/.env` задаёт, кто отвечает, когда у основного
кончился лимит, он упал или недоступен. Связка `gemini` плюс `groq` работает
хорошо: Gemini понимает скриншоты, Groq отвечает за секунду и не кончается
так быстро.

Переключение происходит, только если ответ ещё не начал приходить, иначе
текст смешался бы. Скриншот запасному без зрения не отправляется, вместо
этого показывается понятная ошибка. В панели видно, кто именно ответил.

Когда запасного нет и лимит исчерпан, расширение пишет об этом
по-человечески: сколько запросов в минуту разрешено и через сколько секунд
повторить.

Бесплатные тарифы иногда отвечают 429 или 503. Сервер сам повторяет запрос до трёх раз. Паузу он берёт из ответа провайдера:
заголовок `Retry-After` либо поле `retryDelay` в теле ошибки, как у Gemini.
Пользователь видит только чуть более долгий ответ. Число попыток меняется
через `THELPER_RETRIES`.

Только у `gemini` и `anthropic` есть зрение, поэтому `Alt+S` со скриншотом
работает лишь на них. Остальные вернут понятную ошибку.

Если платить, стоимость тысячи вопросов у Anthropic примерно такая:

| Модель | Примерно |
|---|---|
| `claude-opus-5` | 40 долларов |
| `claude-sonnet-5` | 16 долларов |
| `claude-haiku-4-5` | 8 долларов |

Модель меняется через `THELPER_MODEL`, параметры раздумий сервер подбирает сам.

## Ограничения

- Сервер должен быть запущен, иначе расширение молчит.
- На настоящем экзамене такое использование нарушает правила площадки.
  Инструмент рассчитан на тренировочные тесты, самопроверку и отладку
  собственной LMS.
